TANUI 90-DAY CHALLENGE — PUBLISHING GUIDE

This folder contains:
- index.html: the website
- robots.txt: allows search engines to crawl the site

FREE PUBLISHING OPTION: GITHUB PAGES

1. Sign in at https://github.com/ (or create an account if eligible).
2. Create a new PUBLIC repository, for example: tanui-90-day-challenge.
3. Upload index.html and robots.txt from this folder to the repository's
   main/root folder. Do not upload the ZIP itself as the website.
4. Open the repository's Settings -> Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will publish the site at a URL similar to:
   https://YOUR-USERNAME.github.io/tanui-90-day-challenge/

GET IT DISCOVERED ON GOOGLE

1. Open https://search.google.com/search-console/
2. Add the published website URL as a URL-prefix property.
3. Verify ownership using one of Google's offered methods.
4. Use URL Inspection to request indexing of the homepage.

IMPORTANT
- Publishing makes the site public; anyone with its address can visit it.
- Google indexing is not instant or guaranteed; it may take days or longer.
- The challenge saves progress in each visitor's own browser storage.
  Progress does not sync between devices or between different visitors.
- This is a static site; it has no accounts or server-side database.
- Avoid adding private personal information to the public website.
